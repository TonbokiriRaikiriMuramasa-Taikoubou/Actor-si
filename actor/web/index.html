        Using Actor

        1. Create a skill

        Add skills/<name>/SKILL.md. Set the frontmatter name in kebab-case, such as my-skill. The format follows Gemini skills. You can also draft one from the sidebar.

        2. Apply skills

        • Click a skill in the sidebar to pin it (you can stack multiple skills).
        • Type / in the composer to invoke a skill.
        • If no skill is specified, Actor selects skills from your request when the match score meets the threshold.

        3. Connect to a live model

        The easiest way is to click 🔑 API key at the lower left, paste a Google AI Studio key, and choose “Save and connect.” The key is stored in .actor/api_key (gitignored). A GEMINI_API_KEY value in .env takes precedence. Without a key, Actor uses its built-in simulator.

        4. Export a skill

        Click “ZIP” to export a package that can be uploaded to the Gemini app. The archive contains SKILL.md at its top level.

        5. Chat with a resident bot

        Open a room from the “Rooms” tab to chat with a resident bot started with actor bot --room <name>. Messages are appended to the room, and bot replies appear automatically.
