        スキル

        Actor の使い方

        1. スキルを作る

        skills/<name>/SKILL.md を置くだけ。frontmatter の name は my-skill のような kebab-case にします。Gemini のスキル仕様と同じ形式です。サイドバーの「会話からスキルを作る」で生成もできます。

        2. スキルを適用する

        • サイドバーのスキルをクリック → 固定適用（複数可・スタック）
        • 入力欄で / → スキルを呼び出し
        • 何も指定しなければ、依頼文から自動選択（閾値つき）

        3. 実モデルに切り替える

        いちばん簡単なのは左下の 🔑 API キー：Google AI Studio のキーを貼り付けて「保存して接続」で、その場で実モデルに切り替わります（保存先 .actor/api_key・gitignore 済み）。.env の GEMINI_API_KEY=... を書いた場合はそちらが最優先です。未設定の間は内蔵シミュレータが応答します（このUIの動作確認用）。

        4. 持ち出す

        「ZIP」ボタンで、Gemini アプリにアップロードできる形式（最上位に SKILL.md）で書き出します。

        5. 常駐ボットと話す

        サイドバーの「ルーム」タブでルームを開くと、actor bot --room <名前> で動いている常駐ボットとそのまま会話できます。発言はルームに追記され、ボットの返事は自動で流れてきます。

        キーボード

        • Enter 送信 / Shift+Enter 改行
        • ↑↓ 候補選択（/ メニュー） / Tab 確定
        • Esc 候補を閉じる
