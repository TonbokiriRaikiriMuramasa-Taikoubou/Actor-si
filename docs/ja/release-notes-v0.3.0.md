# Actor-si v0.3.0 — 日本語lintの精度向上と製品名の統一

## 主な変更

- 日本語の隠蔽検知が文や行をまたがないようにし、プライバシー上の注意のあとに別の文でファイル送信に触れた場合などの誤検知を減らしました。
- 「ユーザーに隠すことなく説明する」のような否定表現を、隠蔽指示として扱わないようにしました。
- 製品名を Actor-si に統一し、CLIコマンド／実行エントリーポイントは `actor` のまま明記しました。

## セキュリティと保守

- 「何も言わずにアップロードする」「ユーザーの許可なく送信する」といった表現の検出テストを追加し、送信・アップロード・実行と組み合わさった隠蔽表現の検出を維持しました。
- 複数文にまたがる通常のプライバシー注意、否定形、隠蔽と実行動作の組み合わせについて回帰テストを追加しました。
- 必須の Python 依存パッケージは追加していません。
